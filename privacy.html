隱私政策

最後更新：2026-09-30

1. 適用範圍

本隱私政策適用於波格思股份有限公司（PoolGress，下稱「我們」）提供的 PoolGress 行動應用程式（下稱「本 App」）、合作球館內的 PoolGress 數位球桌，以及 www.poolgress.com 網站。使用本服務即表示您了解並同意本政策所述的資料處理方式。

2. 我們收集的資料

  • 帳號資料：透過 Apple 或 Google 登入時，由該平台提供的帳號識別碼、電子郵件地址與姓名。若您在 Apple 登入時選擇「隱藏我的電子郵件」，我們只會收到 Apple 提供的轉寄地址。
  • 個人檔案：您設定的暱稱、帳號名稱（@ID）、大頭貼、代表色與自我介紹。
  • 大頭貼照片：您用手機相機拍照，或從相簿選擇一張照片作為大頭貼時，我們只會上傳您選定並裁切、壓縮後的那一張照片。
  • 打球紀錄：每一局的關卡、球館與球桌、日期時間、每一球是否成功、成功球數、獲得的星數，以及您是否將該局加入收藏。
  • 遊戲影片：您在數位球桌上挑戰關卡時，球桌上方的攝影機會錄下球桌桌面，用於產生您的擊球回顧影片與進球軌跡分析。攝影機只拍攝球桌範圍，但您或旁人的手部、身體可能會入鏡。
  • 撞球筆記：您建立的筆記內容（文字與球型圖），以及您傳給好友或好友傳給您的筆記。
  • 好友關係：您送出與收到的好友邀請，以及雙方同意後成立的好友名單。
  • 同意紀錄：您第一次登入時，同意服務條款（含錄影）的時間。
  • 教練申請：您在網站「找教練」頁（App 的「我要找官方教練」也會開啟這一頁）填寫的稱呼、LINE ID 或手機、撞球程度、想學的內容、希望的地區或球館、方便的時段、指定教練與補充說明。為了防止濫用，我們會保存您連線 IP 位址的雜湊值（無法還原成原本的 IP），不保存 IP 位址本身。教練申請不需要登入，也不會與您的 App 帳號連結。

本 App 只會在您主動操作時使用手機相機：掃描球桌與好友的 QR Code，以及拍攝大頭貼。掃描 QR Code 的畫面不會上傳或保存。相簿只會讀取您選擇的那一張照片。我們不會收集您的精確位置、通訊錄、手機麥克風，或手機上的其他檔案。

3. 資料用途

我們僅將上述資料用於：

  • 提供登入、闖關進度、星數與關卡解鎖、擊球回顧影片等核心功能
  • 讓您搜尋其他使用者、送出與接受好友邀請、傳送與接收撞球筆記
  • 聯絡您、為您配對合適的教練（教練申請的聯絡方式只用於這個目的）
  • 維護服務安全、處理客服問題，以及改善產品

4. 其他使用者看得到的資料

  • 所有已登入的使用者都可以搜尋並看到您的暱稱、帳號名稱、大頭貼、代表色、自我介紹、玩家等級與總星數。
  • 您的打球紀錄明細與遊戲影片只有您自己看得到，其他人只會看到由紀錄計算出的等級與總星數。
  • 您的筆記只有您自己看得到；您主動傳給好友的筆記，對方才看得到。
  • 您送出好友邀請後，對方會看到是您邀請的；您的好友名單不會公開給其他使用者。
  • 您的電子郵件地址不會顯示給其他使用者。

5. 儲存位置

您的資料儲存於 Supabase 平台（Amazon Web Services 東京區域，位於日本）。

6. 委託處理者與外部服務

我們使用下列服務商協助處理資料，各服務商僅在提供其服務所需範圍內處理資料：

  • Supabase：資料庫、檔案儲存與帳號登入服務
  • Apple／Google：第三方登入驗證
  • Cloudflare Turnstile：「找教練」頁的防機器人驗證
  • LINE：收到新的教練申請時，通知 PoolGress 團隊的 LINE 群組。通知內容不含您的 LINE ID 與手機號碼

本 App 內有些按鈕會開啟其他服務，我們不會因此把您的資料傳給這些服務：

  • LINE：點「LINE 線上客服」會開啟 PoolGress 的 LINE 官方帳號，之後的對話適用 LINE 的隱私權政策。
  • PoolGress 網站：點「我要找官方教練」會用瀏覽器開啟本網站的「找教練」頁，只有您填寫並送出後，我們才會收到資料。
  • Google 地圖：點場館的「導航前往」會開啟該場館的 Google 地圖頁面，適用 Google 的隱私權政策。
  • 電話：點場館的「撥打電話」會交由您手機的電話功能撥號。

7. 保存期限與刪除

您的資料於帳號存續期間保存。您可隨時刪除帳號，方式見帳號刪除說明。刪除帳號時，您的個人檔案、打球紀錄、遊戲影片、筆記、好友關係與好友邀請會一併刪除；您已傳給其他人的筆記，會在對方的信箱中一併移除。以 Apple 登入建立的授權會一併向 Apple 撤銷。

教練申請與 App 帳號沒有連結，不會隨帳號一起刪除；如需刪除，請透過下方聯絡方式告訴我們您申請時留下的 LINE ID 或手機。

8. 您的權利

依中華民國《個人資料保護法》，您有權查詢、閱覽、要求複製、補充或更正、要求停止蒐集處理利用，以及要求刪除您的個人資料。暱稱、大頭貼等個人檔案可直接在 App 的「我的」頁面修改；其他請求請透過下方聯絡方式與我們聯繫。

9. 我們不做的事

我們不會跨其他公司的 App 或網站追蹤您，不會投放廣告，也不會出售您的個人資料。

10. 未成年人

未滿法定年齡者，應在法定代理人同意下使用本服務。

11. 聯絡方式

如對本政策有任何疑問，請來信：poolgress@poolgress.com

12. 政策更新

本政策如有重大變更，我們會於本頁公告並更新「最後更新」日期。
