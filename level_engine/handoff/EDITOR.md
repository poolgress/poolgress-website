# Poolgress 關卡工作台

入口：`dist/editor/index.html`。純 HTML/CSS/JavaScript，與教練指南一併部署。

## 操作

1. 從 20 個範例選擇起點，或建立空白題目。
2. 點球庫加入球，拖曳或輸入 8×4 星座標；方向鍵微調。
3. 選「畫路線」後，從球按住拖出虛線箭頭；經過球或庫邊會鎖定接觸點，繼續拖曳可轉折，放開完成。從同一顆球重新拖曳會重畫路線，也可選球後點桌面延伸。這是繪圖輔助，不是物理模擬。
4. 設定流程、擺球、子球、母球、犯規及計分。中文題目與驗證同步更新。
5. 儲存裝置內草稿，或下載 JSON。

## 新版繪圖操作

- 功能列位於球桌下方。「刪除」依當前模式列出球／路線／目標，確認後刪除，球被刪除時同步移除其路線。「重置」確認後清空全部繪圖與袋口，但保留名稱、流程、計分等關卡設定。兩者皆可復原；其他命名草稿不受影響。

- 主要模式互斥：擺球／畫線／設定目標。擺球才顯示球庫與座標；畫線才顯示虛線（預設）／實線選擇；設定目標下分子球與母球的區塊／袋口。完成區塊後保留目前模式，不會自動跳回擺球。
- 畫線不能移動或刪除球、不能操作目標；擺球不能畫線或改目標。線型保存於每条路線的 `style`，舊檔未指定時視為虛線；完整 JSON 保留線型，舊 Table7 不保證支援。

- 白球、灰球、紅球可不限顆數重複加入；1–15 號球仍不能重複。同色球靠陣列位置與畫面序號區分，各自擁有獨立路線。
- 繪圖不受流程球數限制；完整題目仍會檢查單一母球等流程要求，不符合時可先儲存／下載草稿。灰、紅為無編號子球，不能搭配依號碼順序。
- 母球／子球停球區在「吸附」開啟時，矩形起點和終點都吸附到 ¼ 星交點；反方向拖曳同樣適用，关閉時為自由座標。既有區域不會自動改動。
- 「標袋口」提供「子球六袋口」一鍵全選，以及「子球袋口」「母球袋口」兩個獨立逐袋開關。重複點選取消該類目標，不會清掉另一類。
- gray/red 為新球種；完整 JSON 可回匯，舊 Table7 或遊戲端不保證識別這些球種，串接時需擴充解析。

## 5 種流程

- A：01、03、04，無母球、單球、每次重擺。
- B：05–10，固定母球和一顆子球，每桿重擺。
- C：11–13，輪換母球或子球起點，明確匯出每輪的兩顆球。
- D：02、14–18，單局清檯；02 無母球，其餘自由母球。流程與擊球方式分開建模。
- E：19–20，多輪清檯；20 已修正 order/no_contact，並保留第一桿母球停區。

## 檔案契約

完整格式 `format: poolgress.coach-level, version: 1` 有六個主要區塊：`flow`、`setup`、`objectRules`、`cueRules`、`fouls`、`scoring`；`diagram` 保留球型示意，`teaching` 為人工教學提示。`setup.rounds` 明確列出 C 類每輪佈局，`setup.balls` 同時保留圖面比例 fx/fy 與庫鼻原點星座標 x/y。

Table7 交換格式是 `{v:1, data:{v:2,...}, coachSpec:{...}}`，能保存球型及部分既有旗標。`coachSpec` 保留完整六項規則，回匯工作台時使用它；Table7 重新儲存通常不會保留此根層欄位。現有 Table7 `deserializeState` 可能把 `both` 轉成 `ball`，所以再次經舊版編輯器存取後，必須核對母球進袋規則。星座標 `schemaVersion:2` 遊戲檔可匯入，但非已完成的 runtime 串接。

圖面庫鼻範圍来自 Table7 config：left=.0543、right=.9453、top=.0979、bottom=.9014。轉換採 `(fx-left)/(right-left)*8` 與 `(fy-top)/(bottom-top)*4`。這與舊 drill `coords.py` 的簡單 ×8/×4 不同，不能無條件將交換檔放進舊伺服器。

本次只製作 authoring UI；未修改原 table7 網站、遊戲伺服器、相機偵測或 GitHub 專案。部署維持私人權限。

## 驗證

`node scripts/check-editor.cjs` 檢查 20 關規則、原生和交換檔 round-trip、C 類輪次、20 關旗標、座標、衝突與不合法檔案。`node --check dist/editor/editor.js` 檢查 UI 語法。

素材取自使用者提供的 Poolgress 專案 `table7/assets`；範例內容取自同專案 `drill/levels`，僅套用使用者已確認的 20 關規則修正。重新產生範例：`node scripts/build-presets.mjs /absolute/path/to/drill/levels`。
